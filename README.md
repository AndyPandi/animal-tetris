# 동물친구 블록놀이터

아이폰과 안드로이드 홈 화면에 추가할 수 있는 동물 테마 블록 게임입니다.

- 10×20 놀이판과 7가지 기본 테트리스 블록
- 2.5초마다 한 칸 낙하, 착지 후 2초 동안 이동·회전 가능
- 키보드, 큰 터치 버튼, 좌우 쓸기와 탭 회전 지원
- 오프라인 실행 및 플레이를 중단하지 않는 업데이트

## 실행과 설치

GitHub Pages에서 `main` 브랜치의 `/(root)`를 게시합니다. 별도의 빌드나 패키지 설치가 필요 없습니다.

배포된 HTTPS 주소의 `setup.html`을 열어 **오프라인 준비 완료**를 확인한 뒤 홈 화면에 추가하세요. 아이폰은 Safari의 공유 메뉴, 안드로이드는 Chrome의 설치 메뉴를 사용합니다. 홈 화면 아이콘은 `index.html` 게임을 실행합니다.

일반 게임 실행에는 `index.html`을 직접 열어도 됩니다. PWA 오프라인 기능은 HTTPS 또는 개발용 localhost에서 동작합니다. 브라우저 저장 데이터를 삭제했다면 온라인으로 다시 준비해야 합니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면·그림·게임 규칙 |
| `setup.html` | 설치 안내와 오프라인 준비 상태 |
| `manifest.webmanifest` | 홈 화면 앱 설정 |
| `pwa.js` | 서비스 워커 등록 |
| `sw.js` | 오프라인 캐시와 버전 전환 |
| `icons/` | 아이폰·안드로이드 앱 아이콘 |

## 업데이트

게임 파일을 수정할 때는 `sw.js`의 `VERSION`도 함께 올리고 커밋하세요. 업데이트가 준비되면 열려 있는 게임·설치 안내 창을 모두 닫고 다시 실행하면 됩니다. 플레이 중인 게임은 자동으로 새로고침하지 않습니다. 새로 열거나 새로고침하면 새 게임을 시작하며, 진행 상태를 영구 저장하지는 않습니다.
